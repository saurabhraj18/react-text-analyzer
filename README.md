# React Text Analyzer

A simple and interactive React application to analyze and manipulate text efficiently.

## 🚀 Features
- Convert text to Uppercase / Lowercase
- Count words and characters
- Remove extra spaces
- Dark Mode / Light Mode toggle
- Responsive UI using Bootstrap

## 🛠 Tech Stack
- React.js
- JavaScript (ES6)
- Bootstrap
- HTML5
- CSS3
